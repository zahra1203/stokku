# StokKu

Aplikasi mobile manajemen inventaris dan stok barang UMKM berbasis Flutter,
dengan peringatan stok menipis.

## Fitur
- Dashboard ringkasan inventaris dan peringatan stok
- Katalog barang: cari, filter, dan urutkan
- Tambah, ubah, hapus barang dengan validasi masukan
- Penyesuaian stok cepat (+/-)

## Cara Menjalankan
1. Pastikan Flutter SDK terpasang (`flutter doctor`)
2. `flutter pub get`
3. `flutter run`
